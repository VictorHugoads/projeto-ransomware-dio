# Projeto Ransomware - DIO

## Descrição
Este projeto foi desenvolvido como parte do desafio da plataforma Digital Innovation One (DIO). O objetivo principal é implementar um sistema de detecção e mitigação de ransomware, utilizando ferramentas e técnicas para identificar ataques e proteger os sistemas.

## Tecnologias Utilizadas
- **Python**: Linguagem de programação usada para a implementação do sistema.
- **Scikit-learn**: Para análise de dados e criação de modelos de machine learning.
- **TensorFlow**: Utilizado para o desenvolvimento de modelos de aprendizado de máquina.
- **Pandas**: Para manipulação de dados.
- **Jupyter Notebook**: Ambiente interativo para desenvolvimento e testes.
